# 🎓 Student Query Chatbot

A simple and user-friendly **Student Query Chatbot** developed using Python and Flask.  
The chatbot helps students get quick answers to common college-related questions such as courses, departments, admissions, fees, examinations, facilities, and other student services.

## 🚀 Features

- 🤖 Interactive chatbot interface
- 💬 Student-friendly question and answer system
- 🔍 Matches user questions with stored answers
- 📚 College-related information
- ⚡ Fast response using Flask
- 🎨 Modern and responsive chatbot UI
- 🕐 Displays message time
- ⌨️ Typing animation
- 👋 Automatic welcome message
- 📱 Responsive design

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **HTML5**
- **CSS3**
- **JavaScript**
- **JSON**
- **VS Code**
